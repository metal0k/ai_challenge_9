# Структура репозитория

Репозиторий состоит из трёх слоёв: `advent_core/`, `week_NN/` и `advent_cli/`.

`advent_core/` — общий слой. Здесь конфиг, клиент Mistral, параметры генерации,
журнал вызовов, подсчёт токенов, RAG и клиент MCP. Схемы JSON этого слоя лежат
в `advent_core/schemas/`.

`week_NN/` — код одной недели и текст заданий. Неделя — одно приложение,
которое растёт день за днём, а не отдельный файл на каждый день. Схемы первой
недели лежат в `week_01/schemas/`.

`advent_cli/` — точка входа `advent`: корневое приложение, запись демо и
отправка дня.

Рядом с тремя слоями живёт пакет `adventassistant/`. Это ассистент по
документации репозитория и по текущей ветке git. Он не заменяет `advent_cli/`
и не входит в недели `week_NN/`.

Индекс ассистента читает только `README.md`, файлы `docs/**/*.md` и JSON-схемы
из `advent_core/schemas/` и `week_01/schemas/`. Код недель и реестр MCP в этот
индекс не входят.

Команда `index` по-прежнему индексирует только `README.md`, `docs/` и схемы.
Команда `index-review` индексирует те же файлы плюс production Python четырёх
деревьев `advent_core/`, `advent_cli/`, `adventassistant/` и `week_*/`, без
`tests/`.

Локальный watcher PR находится в `adventassistant/watcher.py`, GitHub API
клиент — в `adventassistant/github.py`. Он читает объекты Git без переключения
ветки и запуска кода PR. Кэш индекса, состояние и отчёты лежат в `data/review/`.
