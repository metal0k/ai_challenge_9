# День 33: локальный помощник поддержки

Команды `adventassistant` показывают работу поддержки вымышленного продукта
«Учебный кабинет». Сначала соберите фиксированный индекс FAQ, затем задайте
вопрос с выбранным демонстрационным профилем:

```console
adventassistant index-support
adventassistant support "Почему не работает авторизация?" --user demo-a --ticket AUTH-101
adventassistant support "Почему не работает авторизация?" --user demo-b --ticket AUTH-102
```

`--user` выбирает запись из локальной вымышленной fixture; это не вход в
аккаунт и не аутентификация. MCP-сервер работает только на чтение и после
проверки владельца возвращает один профиль и, если указан, только его тикет.
Сервер не подключён к CRM и не может отправить письмо, сбросить пароль или
снять блокировку.

FAQ хранится в `adventassistant/support_faq.md`. Отдельный индекс записывается в
`data/rag/index.w07d33.sqlite3` и не смешивается с индексами дней 31 и 32. После
изменения корпуса или его версии пересоберите индекс командой
`index-support`. Отсутствующий или устаревший индекс завершает команду ошибкой
до запросов retrieval.

Общий журнал вызовов сохраняет промпты; здесь они содержат только синтетические
демо-данные. Ответ называет источники и разделы, выбранные retrieval. Если ни
один документ не проходит порог релевантности, помощник направляет вопрос
оператору.
