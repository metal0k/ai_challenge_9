# Неделя 6 — локальный ИИ

День 26: локальная LLM поднята как приватный сервис, запрос идёт по HTTP, три
запроса разной сложности сравниваются с облачной `ministral-14b-latest`.

Точка входа — `adventlocal` (`week_06/cli.py`), отдельная от `advent`: локальный
сервер — отдельный процесс, а не подкоманда недели.

## Как запустить сервер

Сервер — LM Studio, модель `ornith-1.5-9b` (Q4_K_M, arch qwen35, рассуждающая),
идентификатор `ornith`. Видеокарта RTX 3070 8 GB. Запуск — скриптом из соседнего
проекта `LMStudio_tools`:

```powershell
.\start-local-llm.ps1 -Context 57344
```

Демо модель **не загружает и не перезагружает**: LM Studio общий с другими
сессиями, перезагрузка рвёт их состояние. `adventlocal status` только проверяет
сервер (exit 2 с подсказкой, если модели нет или она не `loaded`).

### Почему контекст 57344, а не 73728

Дефолт скрипта — 73728. С ним на RTX 3070 остаётся свободно 344 MiB VRAM, и
скорость падает с ~53 до 15–20 tok/s: кодовый запрос занял 188 s. С
`-Context 57344` свободно 719 MiB, скорость ~50 tok/s. Это «обрыв» по VRAM:
ухудшение не плавное, а скачком, поэтому демо работает с запасом.

## Команды

```bash
uv run adventlocal status                 # загруженные модели сервера по HTTP, state, контекст, квантизация
uv run adventlocal status --all           # плюс не загруженные модели
uv run adventlocal status --cli           # плюс `lms ps` (только по явной просьбе)
uv run adventlocal ask "вопрос"           # один запрос: reasoning на stderr, ответ на stdout
echo "вопрос" | uv run adventlocal ask    # вопрос из stdin
uv run adventlocal ask "..." --no-show-thinking
uv run adventlocal compare                # fact, alice, palindrome: локально и в облаке
uv run adventlocal compare --no-cloud     # только локальная модель
uv run adventlocal compare --runs 5 --tasks alice
```

Общие флаги: `--model` (по умолчанию `ornith`), `--url` (или `ADVENT_LOCAL_URL`,
по умолчанию `http://127.0.0.1:1234`), `--max-tokens` (8192: кодовый запрос тратит
до ~3300 токенов на reasoning), `--deadline` (общий предел вызова, 600 s).

- `lms ps` будит headless-сервис LM Studio и сбрасывает его settings.json, поэтому
  `status` его не вызывает, пока не передан `--cli`; ни демо, ни репетиция `--cli`
  не используют.
- Сэмплинг локальной модели — режим «precise» с карточки: temperature 0.6,
  top_p 0.95. Облако получает серверные умолчания (`temperature` не передаётся).
- Persona `default_system.md` не подмешивается ни локально, ни в облаке: она
  гасит reasoning.
- `compare` не зависит от `ADVENT_BASE_URL`: облачная часть всегда ходит в облако.
  Без `MISTRAL_API_KEY` она пропускается с предупреждением.
- Каждый вызов пишется в `logs/calls.jsonl` (`week=6`, `day=26`).

## Задачи и проверки

| id | уровень | проверка |
|---|---|---|
| `fact` | простой | ответ после снятия форматирования — «Канберра» / «Canberra» |
| `alice` | рассуждение | маркер `ОТВЕТ:`, верный ответ 3 |
| `palindrome` | генерация кода | 7 скрытых тестов: 2 латиница, 2 кириллица, 3 негатив |

Всё проверяется кодом, без LLM-судьи. Скрытые тесты называют состав прямо:
кириллица в русском промпте про «знаки препинания» — честная проверка, а не подвох.

## Остаточный риск: исполнение кода модели

Код из ответа модели исполняется в отдельном процессе, но **это не песочница**.
Что сделано: статический отказ до запуска (`ast`: импорт всего, кроме `re`,
`string`, `unicodedata`, `typing`; вызовы `open`/`eval`/`exec`/`compile`/
`__import__`/`input` и др.; атрибуты с `__`) — verdict «небезопасный код, не
исполнялось»; процесс `python -I -S` с окружением из одного `SYSTEMROOT` и `PATH`
(без ключей из `.env`), в пустом временном каталоге; timeout 10 s с `kill`; вывод
ограничен 64 KB. Чего нет: изоляции файловой системы и сети на уровне ОС. Умышленно
обходящий статическую проверку код может навредить — для демо на простой задаче
риск принят.

## Цифры

Замеры до реализации (2026-10-06, один прогон): `alice` — ornith 3 ✓ (19.8 s,
974 токена), ministral-14b ошибается на этой формулировке; `alice` на банковой
формулировке, 5 прогонов: ministral-14b 1/5, ornith 5/5. Один прогон — не
