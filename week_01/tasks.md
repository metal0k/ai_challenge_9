# Week 01

## Day 01
Напишите минимальный код, который:
👉 отправляет запрос в LLM через API
👉 получает ответ
👉 выводит его в консоль или простой интерфейс (CLI / Web)

Результат:
Код, который отправляет запрос в LLM через API и получает ответ

Формат:
Видео + Код


## Day 02

🔥 День 2. Формат ответа

Отправьте один и тот же запрос, но:
👉 добавьте явное описание формата ответа
👉 добавьте ограничение на длину ответа
👉 добавьте условие завершения ответа (stop sequence или явную инструкцию)

Сравните ответы:
👉 без ограничений
👉 с ограничениями

Результат:
Один и тот же запрос с разным уровнем контроля ответа через API

Формат:
Видео + Код

Уточнения автора курса (01.09.2026), пересказом:

- Ограничения должны быть **настраиваемыми переключалками на разные режимы**,
  а не зашитыми в код константами.
- Цель — получать одинаково структурированный ответ независимо от количества
  запросов к модели.
- Формат не обязан быть JSON: подойдут JSON Schema (вида `items: [{name, age}]`),
  Markdown или YAML — важно, чтобы ответ был детерминирован в рамках формата.
- Условие завершения понимается шире, чем параметр `stop`: это диалог, в котором
  модель задаёт уточняющие вопросы и сама решает, когда данных достаточно, после
  чего выдаёт итоговый результат.

Дословные реплики не приводятся: это приватный чат курса, а репозиторий публичный.
